03 / METHODOLOGY & SCOPE

How to read the results.

01 / SOURCE

Real saved outputs

Every model caption, supplied fact string and measured nutrition value is joined by the original test dish ID. The 507 photos come from matching RGB files in the Nutrition5k source imagery.

02 / EVALUATION

Faithfulness on five fields

Calories, protein, fat, carbohydrates and mass are extracted with the experiment's historical regex. A value counts as faithful if it is parsed and falls within ±1 of its supplied fact.

03 / LIMITS

No training or live inference

This explorer displays saved experiment outputs. Textual inputs also contain ingredient metadata from the dataset. Numeric agreement does not guarantee nutrition prediction accuracy.
